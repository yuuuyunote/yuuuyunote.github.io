実績

Discordコミュニティ運営・Bot開発・note記事作成などの活動実績をまとめています。

  • 2024年05月〜 現在 · Discord運営

    Guide Base + の運営

    Discordの設定・セキュリティ・Bot運用に関する情報を発信する日本語コミュニティサーバーを有志で立ち上げ・運営。Wick / Sapphire / Double Counter 等の複数Botを組み合わせた多層防御設計を実装し、正規表現を活用したフィルタリング体制を構築。海外コミュニティとの連携も行っている。

  • Discord Bot 開発 · Powered by Guide Base +

    Ward — 迷惑サーバー自動検知Bot

    招待リンクの送信を監視し、迷惑サーバーへの誘導を自動検知するDiscord Bot。Discord公式の招待リンクだけでなく、国内外17の掲示板・宣伝サイトへのサーバーリンクも検知対象に含めている。検知時はメッセージ削除・Timeout・ログチャンネルへの通知の3アクションのみに絞り、モデレーションの負荷を抑える設計。

  • 2024年〜 現在 · note執筆

    Discord活用ガイド記事シリーズ

    Starboard活用法・Statbot Statdocks・Xenon バックアップ手順・top.gg アナウンス機能など、Discordの実務的なノウハウをnoteに体系的に記事化。技術用語への注釈や独自の考察を織り交ぜた解説スタイルで、国内Discordユーザーに向けた一次情報として機能している。

  • 2024年〜 現在 · Discord運営 / 海外連携

    複数サーバー運営・top.gg日本語化サポート

    Guide Base + に加え、2,000人規模の別サーバーの運営にも携わる。海外コミュニティとの連携では、top.gg CEO の Veld 氏から「日本人ユーザーを増やすために何が必要か」という相談を受け、日本語対応の必要性を提案。その後の日本語化対応のサポートを行い、日本語圏のDiscordユーザーがtop.ggを利用しやすい環境整備に貢献した。
